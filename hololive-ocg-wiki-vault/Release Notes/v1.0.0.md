# v1.0.0 Release Notes

**Release Date:** September 21, 2025
**Repository:** [hololive-ocg-wiki](https://github.com/lichingchester/hololive-ocg-wiki)

## Major Milestone: First Stable Release

First stable release of Hololive OCG Wiki — a fan-made web application providing comprehensive card information, deck building tools, and multilingual support for the Hololive Official Card Game community.

## Dataset

- **1,398 cards** with complete data
- **6 languages:** Japanese, Traditional Chinese, English, Korean, Indonesian, Thai
- Translations generated through LLM processing of official sources

## Architecture

### Frontend (Nuxt 3 + Vue 3)

- Single Page Application (SSR disabled)
- Vue 3 Composition API
- Shadcn-vue UI components on Reka UI primitives
- `@nuxtjs/i18n` with seamless locale switching
- Responsive design for desktop and mobile

### Backend (Cloudflare Edge)

- Cloudflare D1 Database (SQLite, normalized schema)
- Cloudflare Workers (TypeScript edge functions)
- FTS5 full-text search with intelligent LIKE fallback
- RESTful API with filtering, search, and pagination

## Key Features

- **Full-text search** across card names, abilities, skills, tags with relevance ranking
- **Multi-criteria filtering** by color, type, rarity, bloom level, set
- **Detailed card views** with translations, arts, oshi skills, Q&A
- **6 complete localizations** with locale-aware URLs
- **Virtual scrolling** for large card lists
- **Dark/light mode** with system preference detection
- **Deck builder** tools
- **PWA features** with offline capability preparation

## Performance

- FTS5 indexes providing ~10x faster search vs LIKE queries
- Component lazy loading via Nuxt auto `Lazy*` components
- Debounced API calls (300ms)
- Edge computing for global low-latency responses
- Paginated results with LIMIT/OFFSET

## Known Limitations

- Search response times occasionally reaching ~2.4s (optimization in progress)
- Some filter combinations may need performance tuning
