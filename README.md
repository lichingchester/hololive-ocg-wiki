# Hololive OCG Wiki

![GitLab Release](https://img.shields.io/gitlab/v/release/70581893)

Hololive OCG Wiki is a fan-made resource for the Hololive Official Card Game. The project is built with Nuxt.js and aims to provide comprehensive card information, deck building tools, and other resources for players.

## Our Discord Community

Welcome to join our [Discord community](https://discord.gg/qTuMPeuEN2) to report issues and track the latest updates of this project!

## Contributing

If you're interested in contributing to Hololive OCG Wiki project, please read our [contributing docs](CONTRIBUTING.md) before submitting a pull request.

## Dataset

This dataset contains translations for 1,398 Hololive OCG cards (as of 21 September 2025). The source data was collected from the [Official Hololive OCG Website](https://hololive-official-cardgame.com/cardlist/cardsearch/?keyword=&attribute%5B%5D=all&expansion_name=&card_kind%5B%5D=all&rare%5B%5D=all&bloom_level%5B%5D=all&parallel%5B%5D=all) and processed through an LLM model to generate multilingual translations. The cards are available in six languages: Japanese, Traditional Chinese, Simplified Chinese, English, Korean, and Indonesian.
